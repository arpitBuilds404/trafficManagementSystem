
# Smart Traffic Management System – Gurugram (DEMO Mode)

React + Leaflet/OpenStreetMap frontend and FastAPI backend with a trained traffic forecasting model. No API keys required.

## Run (Windows)

Install Python 3.10+ (tick "Add to PATH") and Node.js 18+ LTS.

Double-click `start-all.bat` to start the backend (port 8000), frontend (port 5173), and launch the browser.

Alternatively, run `start-backend.bat` and `start-frontend.bat` in separate terminals.

### Manual Setup

Backend:
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

Frontend:
```bash
cd frontend
npm install
npm run dev
```

Frontend: http://localhost:5173

API Docs: http://localhost:8000/docs

## What Is Real and What Is Demo?

- **Demo (simulated):** Traffic readings are generated by a simulator and replayed on a demo clock running 15x faster than real time (5 demo minutes ≈ 20 seconds). The UI displays DEMO MODE.
- **Real:** The forecasting model uses ridge regression with a direct 6-step forecast (+5, +10, +15, +20, +25, +30 minutes).
- **Model inputs:** Last six 5-minute speed readings of each segment, time of day, and typical segment demand.
- **Training:** The model is initially trained using 21 days of synthetic history (17 training days / 4 testing days) and saved as `backend/model.npz`.
- **Reported accuracy:** On the four held-out days, its +30-minute error is approximately 2.9 km/h, compared with 3.8 km/h for the "assume no change" baseline.
- **Not available:** Database, Neo4j (not configured), and vehicle counts.
- **Real data integration:** Replace `demo_data.generate` / the simulator in `engine.py` with sensor readings and retrain using `ml.train`.

## Features

- **Overview Dashboard:** Live KPIs, congestion-coloured map, 15/30/60-minute predictions, route options, alerts, and 24-hour chart.
- **Traffic Monitoring:** Interactive map, search, and filters.
- **Prediction:** 30-minute forecasts, charts, timeline, actual-versus-predicted checks, and model accuracy.
- **Alerts & Incidents:** Automatic alerts, acknowledge alerts, report/clear incidents, and resolved history.
- **Analytics:** 24-hour / 7-day congestion, busiest roads, and per-segment speed forecasts.
- **Route Planner:** Fastest, shortest, and alternative routes for selected junctions, with now / +15 / +30-minute options.
- **Settings:** Alert sensitivity, refresh rate, junction labels, simulation controls, and reset simulation.
- **System Status:** Backend, database, Neo4j, model, WebSocket, last update, and controls.
- **Time of Day:** Jump to rush hour or late night for demonstrations.
